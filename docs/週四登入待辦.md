# 週四登入實測待辦清單

環境連不到 onrender.com，Claude 無法盲測登入。這份清單把「**要登入才會動**」
的所有東西集中，週四一次做完。網址：https://bible-app-xy4g.onrender.com

---

## 0. 前置設定（先做完，否則下面全部會失敗）

- [ ] **部署 Firestore 安全規則**（最重要！）
      `firestore.rules` 只是 repo 檔案，要實際上傳 Firebase 才生效。
      Firebase Console → Firestore → 規則 → 貼上 `firestore.rules` 內容 → 發布。
      （沒做的話：Q&A、投稿審核、同步刪除、內容後台、知識架構編輯全部會權限錯誤。）
- [ ] **部署內容後台網站（新）**：Render → 用 `render.yaml`（已含第二個服務
      `bible-app-admin`，build 指令 `./render-build-admin.sh`）。部署後會有第二個網址，
      例如 `bible-app-admin.onrender.com`。這是你管理內容用的，一般讀者用原本的網址。
- [ ] **Firebase Authentication 啟用 Google 供應商**（Console → Authentication → Sign-in method）
- [ ] **授權網域**加入**兩個**網址：讀經 `bible-app-xy4g.onrender.com` 與
      後台 `bible-app-admin.onrender.com`（Authentication → Settings → Authorized domains）
- [ ] **Google Cloud OAuth**：授權的 JavaScript 來源與重新導向 URI 要有
      讀經、後台兩個 onrender 網址 + `https://bible-app-c0eac.firebaseapp.com`
- [ ] （選）Apple 登入：要在 Apple Developer 建 Service ID + Firebase 啟用 Apple 供應商，
      才會動；不做就先只用 Google。

---

## 1. 登入本身

- [ ] Google 登入（設定頁的官方 GIS 按鈕）→ 能跳出帳號選擇並登入成功
- [ ] 官方按鈕沒反應時，「改用備用方式登入」（同網域轉址）也能登入
- [ ] 登入後設定頁顯示帳號名稱／email
- [ ] 登出能正常登出
- [ ] **登入完不再白屏**（之前的白屏已加 8 秒 timeout + 移除 service worker，週四確認）
- [ ] （選）Apple 登入

> 若登入失敗，看瀏覽器 console 錯誤訊息（redirect_uri_mismatch / popup blocked / 空白頁），
> 這些訊息能直接定位是哪個前置設定沒對。

---

## 2. 雲端同步（登入後）

- [ ] 設定頁「立即同步」成功，顯示「已同步（上傳 N 筆、下載合併 M 筆）」
- [ ] 登入時自動同步有觸發
- [ ] 在 A 裝置加書籤/螢光筆/筆記/證道筆記/讀經計畫進度 → B 裝置同步後看得到
- [ ] **同步刪除（新做）**：A 裝置刪一筆 → 同步 → B 裝置同步後**該筆真的消失、不會復活**
- [ ] 刪除後又重新加同一筆 → 不會被墓碑擋掉（能正常再出現）

---

## 3. 公開註解投稿 + 審核（登入）

- [ ] 一般使用者在讀經頁「投稿公開註解」→ 提交成功（進待審）
- [ ] 你（管理者）在設定頁「內容管理 → 公開註解審核」看到待審
- [ ] 通過 → 讀經頁該節「社群註解」顯示；退回 → 不顯示

---

## 4. 內容後台（**獨立網站**，管理者登入）

後台已從讀經 app 搬到獨立網站（`bible-app-admin.onrender.com`）。

- [ ] 打開後台網址 → 用管理者帳號（kAdminEmail）Google 登入 → 進得了儀表板
- [ ] 非管理者帳號登入 → 顯示「不是管理者」擋住（安全確認）
- [ ] 導讀／註解編輯 → 儲存 → 讀經 app 立即看到（雲端優先合併）
- [ ] 公開註解審核（在後台儀表板）
- [ ] Q&A 審核／回答（在後台儀表板）
- [ ] **知識架構編輯（新）**：平行對照／預表應驗／時間軸／人物，新增後
      讀經 app 的「聖經知識庫」立即看到
- [ ] ⛔ 內容文字由你親寫，Claude 不代寫

---

## 5. 疑問 Q&A（新做，全套需登入）

- [ ] 一般使用者「提問」（首頁 → 疑問 Q&A → 提問）→ 進待審
- [ ] 你（管理者）右上「審核」看到待審問題
- [ ] 進問題詳情，管理操作：**回答／核准公開／退回／設精選** 都正常
- [ ] 回答裡「引用經文」chip 點了會跳到讀經頁對應章
- [ ] 回答加標籤、精選置頂在列表生效
- [ ] 編輯回答後，「回答更新紀錄」保留舊版
- [ ] 問題搜尋（標題/內文/回答/標籤）
- [ ] 收藏問題 → 「我的 Q&A → 收藏」看得到
- [ ] 追蹤問題 → 有新回答時「我的 Q&A → 追蹤」顯示未讀紅點
      （注意：這是 App 內未讀提示，**不是手機推播**；真推播要另接 FCM）

---

## 6. 若要真手機推播（可選，之後再說）

目前「追蹤通知」是 App 內紅點。要真的推播到手機，需接 Firebase Cloud Messaging（FCM）：
web 要 VAPID key + service worker、iOS 要 APNs 憑證。這是額外一整塊，週四若有空再評估。

---
